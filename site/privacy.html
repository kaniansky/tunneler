Privacy policy

Last updated: 2026-10-28

This policy covers Tunneler: the game in the browser, the desktop app and the Android app (com.kaniansky.Tunneler), made by Norko Kaniansky. In short: the game has no ads, no analytics and no tracking. Online games and the daily challenge's leaderboard need an account on the game server - a username and a password, nothing else (no e-mail, no real name). Everything else (split screen, skirmish, replays, maps) works without one and sends nothing anywhere.

What stays on your device

The game keeps these only on your own device, in the browser's or the app's local storage (localStorage and IndexedDB). They are never sent anywhere by themselves, and you can delete them by clearing the site's data or the app's storage, or by uninstalling the app:

  • your settings (language, graphics, sound, controls and so on) and the player name you choose for online games;
  • the replays of your last matches (the newest 20) and the maps you make in the map editor;
  • a random id for this browser or app (on a server without accounts it lets the game server give you your seat back after a lost connection) and the keys of the online games you created;
  • when you are logged in, the login token (session) of your account for each game server - logging out deletes it.

The browser version can also keep the game's own files in the browser's cache so that it starts without a connection. While you are logged in to an account, a copy of your settings, maps and replays is also kept with that account (see Accounts below).

Online games

Split screen and skirmish games run entirely on your device. Only when you choose an online game does the game connect to a game server: by default https://tunneler-online.onrender.com, or another server you set in the app's Settings. That server receives:

  • your account's username (on a server without accounts: the player name you chose), and the chat messages you write;
  • the random id mentioned above, and the version of the game;
  • your moves during a match (the keys you press), the game's own checks and your ping;
  • the name, settings and optional password of a game you create (the password is kept only as a salted hash).

The server needs this to run the game: everyone in the same game sees your name, your chat messages and your tank. It keeps it in memory, while the game room exists; rooms are removed after about 10 minutes without players. When the server restarts (for example when a new version goes live), it writes its open rooms - their players' names, settings and recent chat - to its storage so that the next server can carry the games on, and the next server deletes that copy as soon as it has read it. The server program writes a short technical log (for example when a room is created, or when a player name joins or leaves a room) to its console; it does not record chat messages or IP addresses there.

The server sees your IP address, as every internet server does. The game server uses it in memory only, to limit how many requests one address can make (against abuse), and does not store it. The hosting provider of the default server (Render) may keep standard technical access logs, as described in its own privacy policy. Connections to the default server are encrypted (HTTPS / secure WebSocket).

Accounts

Online games and sending a daily-challenge result need an account on the game server you play on (accounts are per server; a server's operator may also run it without accounts). When you create one, the server stores:

  • your username (your login), and the display name you may choose in Settings - the name everybody sees in online games and on the leaderboard (your username until you change it);
  • if you sign in with Google Play in the Android app: your Google Play Games player id (to know it is you next time) - nothing else from your Google account;
  • your password and your recovery code, but only as salted one-way hashes (scrypt) - nobody, including the server's operator, can read them back;
  • a random account id, and when the account was created and last used;
  • while you are logged in: a copy of your settings, your maps and your replays (the ones on your device; not the server address, the fullscreen setting or the login itself), so that every device you log in on has them - only you can get them; deleting a map or a replay on one device deletes its copy too;
  • the daily-challenge results you send: your place, rounds, kills and time on that day's leaderboard, and the replay of your best match of the day - shown to everyone who looks at the leaderboard. Leaderboards are kept for 30 days.

There is no e-mail address and nothing else about you. On the default server the accounts are kept in the server's storage (a Cloudflare R2 bucket); they are used only to run the game.

Deleting your account: in the game (the browser version or the apps), log in, then Settings → Online → Delete account, and confirm with your password. The account, its login, the settings, maps and replays kept with it, its leaderboard entries and their replays are deleted from the server at once. Logging out only forgets the login on that device. If you have lost both your password and your recovery code, the account can't be recovered and the game can't tell that it is yours; ask on the issues page below and the server's operator deletes it by its username.

Shared replays: if you choose to share a replay as a link, that replay (the match's moves, settings and player names) is uploaded to the game server and kept there, so that anyone with the link can watch it. It is never shared unless you ask for it. A shared link isn't tied to your account: deleting the account doesn't remove replays you shared as links - they stay until the server removes them (on the default server after 90 days).

The Android app

The Android app asks for no permissions beyond network access. Saving a replay as a file writes that file into your Downloads folder; opening a replay file reads only the file you pick. It does not check for updates itself (Google Play or you update it). The desktop app asks GitHub once in a while whether a new version is out; GitHub sees that request like any web request.

This homepage

This homepage uses no cookies and no analytics. It loads fonts from Google Fonts and the list of downloads from the GitHub API; those services receive your IP address with the request, under their own privacy policies. Your choice of language and look is kept in your browser only.

Children

The game is not directed at children under 13 and collects no personal data beyond an account's username (see Accounts). Online chat is between the players of one game room; it is not moderated, and anyone can leave a room at any time.

Changes and contact

If this policy changes, the new version will be published on this page with a new date. Questions? Please open an issue on the GitHub repository's issues page.
