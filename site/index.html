Same game, same look

TUNNELER 2.0 was written by Geoffrey Silverton in 1991 in Turbo Pascal. Tunneler Online is a routine-by-routine rewrite of the decompiled original in JavaScript: tanks, digging, shots, energy, shields, the sounds and the world generator behave exactly like the DOS game - an automated test runs the original next to the port and compares every frame. It even keeps the original's low-res text mode and VGA font.

Split screen

Two players on one keyboard, like in 1991. BLUE on the left, GREEN on the right.

Skirmish

You against 1 to 7 computer tanks - easy, medium or hard - alone or in teams.

Online

Create a game, send the invite link, play with up to 8 tanks from different computers. Friends can watch as spectators.

Modes & settings

Gold rush, infection, survival, king of the hill, shrinking world, capture the flag, base siege, deathmatch - or the original game. Any team setup, three map sizes, friendly fire, a round time limit.

Sounds

The original PC speaker - or realistic and cartoony sound effects. Sounds fade with distance.

Six languages

English, Slovenčina, Čeština, Українська, Русский and Gen Z. Names and chat in any script.

How to play

Each tank starts in its own base. Dig through the dirt (rock can't be dug), find the enemy and shoot it. Moving costs energy, digging more, shooting the most; refuel at any base, repair your shield at your own (and, slower, at a teammate's). Firing while moving digs faster. Win the set number of rounds to win the match.

Download

A small desktop app - the game in its own window, using the web view your system already has (a few MB). Split screen and skirmish work offline; online play uses the public server or your own. It tells you when a new version is out.

Linux

.AppImage / .deb / .rpm / .tar.gz

Needs WebKitGTK 4.1 (most desktops have it). The AppImage: make it executable first (chmod +x, or Properties → Allow executing); it updates itself. The .deb / .rpm update with the admin password - or use the repository below.

Linux repository

Debian, Ubuntu, Mint: add the repository once and the game updates with the rest of your system.

curl -fsSL https://kaniansky.com/tunneler/tunneler-online.gpg | sudo tee /usr/share/keyrings/tunneler-online.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/tunneler-online.gpg] https://kaniansky.com/tunneler/apt ./" | sudo tee /etc/apt/sources.list.d/tunneler-online.list
sudo apt update && sudo apt install tunneler-online

Fedora and other dnf systems:

sudo curl -fsSL -o /etc/yum.repos.d/tunneler-online.repo https://kaniansky.com/tunneler/rpm/tunneler-online.repo
sudo dnf install tunneler-online

Prefer to host it yourself? The server is one Node.js file or a Docker image: docker run -p 8050:8050 ghcr.io/kaniansky/tunneler-online

Privacy

The game and the desktop app collect no personal data. Online, the server keeps game rooms (names, chat, moves) in memory only while a game exists; nothing is stored or shared. The desktop app only asks GitHub whether a new version is out; it connects to a game server only when you choose online play.
