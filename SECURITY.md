# Security Policy

This is a small hobby game, not a security-critical service - but if you find something worth flagging
(e.g. a way to crash the server, take over someone else's tank or room, or inject markup through room
names), please open a private report via GitHub's [Security Advisories](../../security/advisories/new) tab
rather than a public issue.

There's no formal SLA - this is maintained on a best-effort basis.
