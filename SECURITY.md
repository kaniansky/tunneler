# Security Policy

This is a small hobby netplay project, not a security-critical service — but if you find something
worth flagging (e.g. a way to crash the relay server, corrupt another session, or otherwise abuse the
WASM/websocket boundary), please open a private report via GitHub's
[Security Advisories](../../security/advisories/new) tab rather than a public issue.

There's no formal SLA — this is maintained on a best-effort basis.
