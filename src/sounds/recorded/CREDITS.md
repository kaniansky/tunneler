# Recorded sounds - credits

The "recorded" sound style's samples. Every original is CC0 (public domain dedication) or public domain,
so they may be redistributed here (this project is public domain, Unlicense). Crediting is not required;
it is done anyway. `tools/make-sounds.sh <download dir>` downloads the originals and rebuilds these files
(cut, mono 44.1 kHz, faded, levelled, MP3 96 kbps).
