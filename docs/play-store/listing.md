## Checking the counts

```sh
python3 -I -c '
import re
t = open("docs/play-store/listing.md", encoding="utf-8").read()
for lang, body in re.findall(r"^## (\w\w) - .*?\n(.*?)(?=^## |\Z)", t, re.S | re.M):
    blocks = re.findall(r"```text\n(.*?)\n```", body, re.S)
    print(lang, [len(b) for b in blocks])'
```
